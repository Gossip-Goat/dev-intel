# Sources

One module per source, each with a `TERMS.md` saying who checked the site's terms and robots.txt, when, and what they allow.

No paid data is licensed yet. Candidates, in priority order:

| Source | Gives | Status |
| --- | --- | --- |
| Domain developer API | New-development listings, agent contacts | Not yet applied for |
| PropTrack (REA) or CoreLogic | Listings, sales and settlement history | Not licensed |
| Council DA portals (Brisbane Development.i, Gold Coast PD Online, others per LGA) | Lodged and approved projects | Check each portal's terms |
| Developer project websites | Brochures, price guides, enquiry contacts | Add to config/allowlist.yaml after review |

realestate.com.au is blocked in the fetcher because its terms prohibit scraping.
